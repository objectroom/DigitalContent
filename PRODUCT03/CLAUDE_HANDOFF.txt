이 ZIP의 index.html과 assets 폴더, 루트 SVG는 최신 배포본(3cafcfe)이다.
대상 저장소에서 실제 PRODUCT03 경로와 GitHub Pages 배포 방식을 먼저 확인한 뒤,
index.html, assets 폴더, 루트 SVG를 같은 상대 경로로 반영한다.
index.html만 단독 교체하면 이미지, 스크립트, 3D 모델이 누락될 수 있다.
팀 사이트에서 PRODUCT03으로 들어오는 링크와 PRODUCT03의 상위 페이지 링크를 확인한다.
로컬에서 확인할 때는 ZIP을 푼 폴더에서 HTTP 서버를 실행하고 브라우저로 연다.

사용 시나리오 영상은 아직 없다. 파일이 완성되면 assets/video/scenario.mp4에 넣고,
index.html의 사용 시나리오 구간에 있는 MP4 <source> 주석을 해제한다.
배포 전 문제·해결 아이소메트릭 스크롤, 핵심 기능 갤러리, 작동 방식 이미지,
신호 체계, 다이얼 시연, 3D 뷰어와 모바일 화면을 확인한다.

수정본에서는 화면 구성 CSS와 아이소메트릭 스크립트가 index.html에 내장됩니다.
